MoonDigest

基础 · 读字幕 + AI 总结

打开视频页就能抓字幕、复制或下载，并在侧边栏让 AI 总结和问答。

字幕与专注模式

没有该语言的字幕时，使用 YouTube 机器翻译。

AI 模型平台

支持 OpenAI 兼容协议（OpenAI / DeepSeek / 智谱 / MiniMax / Moonshot / OpenRouter / Ollama 等）。

还没有配置平台，点击下方按钮添加。

系统提示词

每次回答都遵守的规则，如语言、长短、时间戳格式。总结格式别写在这里，它对追问也生效。

AI 总结要求

所有「AI 总结」按钮（弹窗、侧边栏、播放器、专注模式）发出的第一条消息。留空时这些按钮只打开侧边栏。

管理追问

有回答后显示在输入框上方，点一下就发送。每行一条，最多 12 条；侧边栏「管理追问」里也能增删。

笔记格式

复制 Markdown 和下载 .md 都按这里生成笔记。写入 Obsidian 也一样。

内容

把这个视频最近一段侧边栏对话写进笔记末尾的「AI 问答」段落。笔记已存在时再次写入 Obsidian 只替换这一段，其余内容不动；你在这一段标记之间改的文字会被替换。写入过一次后，这个视频每次 AI 回答完都会自动更新这一段。

进阶 1 · 收藏夹分拣台（仅 B 站）

打开分拣台

把一个收藏夹里的视频批量交给 AI 粗分和细看，连起来读，判断哪些值得看。

分拣过或打过标签的视频，在收藏夹、视频页、首页和搜索结果里显示一个小标记。虚线框表示只做过标题粗分。

进阶 2 · Obsidian（可选）

把字幕、AI 对话和分拣结果写进 Obsidian，可以单个写，也可以整个收藏夹批量写。

配置指引

  1. 在 Obsidian 社区插件市场安装并启用 Local REST API with MCP。
  2. 在插件设置中勾选 Enable Non-encrypted (HTTP) Server，地址通常为 http://127.0.0.1:27123。
  3. 复制 API Key，回到本页填写“Local REST API 地址”和“Local REST API Key”。

连接

写入位置

所有写入 Obsidian 的笔记都放这里，分拣台批量写入也一样。可用变量：{{site}} 网站（bilibili / youtube）、{{created}} 写入日期、{{upload_date}} 视频发布日期、{{author}} UP 主或频道、{{id}} 视频号（BV 号或 YouTube ID）、{{bvid}} BV 号（YouTube 视频为空）。示例：MoonDigest/{{site}}/{{author}}

数据与存储

所有功能共用的本地数据：字幕缓存、AI 对话、分拣结果和备注。都存在浏览器本地，不上传；到了上限怎么处理，写在每一行里。
