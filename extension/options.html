进阶 1 · 收藏夹批量阅览（仅 B 站）

把一个收藏夹里的视频批量交给 AI 粗分和细看，连起来读，判断哪些值得看。

分拣设置

与分拣台里的“设置”是同一份，改哪边都一样。

标题粗分：只看标题和简介，几十个一批，快、省钱，分成 建议删 / 建议留 / 待定。
字幕细看：读字幕（没有字幕时读简介和评论），一次一个视频，慢一些，给出一句话总结、3 个要点、判断和建议标签。

关：快、省（30 个标题约 3 秒）。开：判断更细，但慢约 6 倍、费约 5 倍 token。目前只对 DeepSeek 生效。

高级（一般不用改）

留空就是自动。只有提示“输出被截断”时才需要调大。

进阶 2 · Obsidian 知识库

把字幕、AI 对话和分拣结果写进 Obsidian，可以单个写，也可以整个收藏夹批量写。

配置指引

视频教程 · GitHub 仓库地址

  1. 在 Obsidian 社区插件市场安装并启用 Local REST API with MCP。
  2. 在插件设置中勾选 Enable Non-encrypted (HTTP) Server，地址通常为 http://127.0.0.1:27123。
  3. 复制 API Key，回到本页填写“Local REST API 地址”和“Local REST API Key”。

连接

笔记格式

支持变量：{{created}} / {{upload_date}} / {{author}} / {{site}} / {{id}} / {{bvid}}，示例：Clippings/{{site}}/{{created}}

分拣台的摘录篮和整个收藏夹的笔记写到这里。

笔记属性（Frontmatter）

勾选需要写入到 Obsidian 属性区的字段。

自定义属性

支持默认属性的变量映射，比如 `{{upload_date}}`、`{{created}}`、`{{site}}`、`{{video_id}}`、`{{author_url}}`、`{{cover}}`、`{{duration}}`
